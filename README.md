# 考公笔记漫游 0.10.1

包含自由拖动浮动工具栏、一键入词典和技巧宝典体系匹配。技巧宝典匹配会扫描题干和选项文本，并显示命中的“如果…那么…”线索规则。人工确认后将关联写入题目 YAML，并记录到技巧宝典的老师/体系分析中；同一方法和分析位置重复确认时更新原记录。蒙题提交时会调用考公技巧宝典，将个人练习摘要归档到模块与题型路径下；不新建老师方法节点。同题后续填写总结会更新同一归档记录。

需要同时启用 `exam-technique-handbook` 0.7.0 及兼容的考公词典插件。此版本用于 Obsidian/iPad 实测，静态与回归检查通过不代表设备运行已验证。BRAT 仓库：`vfjy12/gongkao-note-roamer`。
