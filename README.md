# 考公笔记漫游 0.5.4

为考公题库设计的 Obsidian 漫游学习插件，主要适配 iPad mini 6 与 Apple Pencil，同时兼顾 Windows 整理。

0.5.4 为蒙题和考试模式增加“临时草稿”：开启后 Apple Pencil 可直接在当前题面圈画，手指仍负责滚动、翻页和点击选项；Windows 可开启后用鼠标测试。笔迹按题目暂存，切题后仍在，但退出当前学习模式、重新开始、交卷或关闭 Obsidian 即清空，不写入 Markdown、不生成附件，也不参与同步。工具栏支持撤销上一笔和二次确认清空本题；整卷模式只为屏幕附近且已有笔迹的题面分配高清画布，降低长卷在 iPad 上的内存占用。

0.5.3 是加载校验版：清理了 Windows 粘贴产生的同 ID 重复目录，并使版本号可直接用于确认 Obsidian 已卸载旧运行实例。

0.5.2 在卷子或专题名称下方增加集合级“查找潜在链接”：它从考公词典的已有词条标题与别名出发，扫描整套卷或整个专题的题目和答案解析，只列出尚未建立双链的同名文字。候选默认不勾选，预览并确认后才写入；同名词对应多个词条时自动跳过。批量备份改为基于稳定插件 ID 的路径，不再因旧版文件夹被移出而报 `ENOENT`。

0.5.1 增加蒙题和考试模式的“词条双链预览”：默认关闭时按普通文字显示，手动开启后以紫色双链显示并允许点击/悬浮预览。

0.5.0 在 iPad 上支持直接新建收件箱词条而不展开编辑栏，并可按本题、当前卷、当前专题或全部题库预览、勾选和批量补齐正文双链；最近一次批量回链可从命令面板撤销。文字选区、长按选择手柄和屏幕边缘手势不触发左右翻题。

0.4.9 将考试结束后的“重新考试 / 返回模式选择 / 返回首页”移到成绩页标题区，避免完成整卷后还要滚到页面底部操作；原笔记继续默认折叠 YAML，并在返回按钮正下方提供展开/折叠。

## 组卷方式

- 按卷子：`paper_id` + `question_no`，恢复原卷顺序。
- 按专题：读取 `topics` / `topic`。
- 按模块：读取 `module` / `major_module`。
- 按地区：读取 `region`。
- 按错因：读取 `mistakes` / `mistake`。
- 按状态：读取 `status` / `state`。
- 可叠加年份、科目、模块、状态筛选。
- 按卷子严格使用该卷全部题目，不进行抽样。
- 按专题、模块、地区、错因或状态组题时，可设置本次题量；默认从去重后的题池随机抽取 20 道。
- 动态组合依据 `source_qid` 去除不同卷别中的同一道原题；按卷子时保留原卷结构。

每道题必须是独立 Markdown。插件在漫游时依据 YAML 动态组合，不要求预先生成“整套卷文件”或“专题合卷文件”。

## 学习模式

- 模式卡片单击只选择；在短时间内双击同一张“卷子精读 / 蒙题训练 / 考试模式”卡片可直接开始，避免再移动到页面底部点开始。

### 卷子精读

- 把本次组合的全部题目铺成完整卷面，而不是逐题随机漫游。
- “上下连续”适合整卷精读；“左右分页”支持鼠标滚轮、按钮、键盘方向键和 iPad 横向滑动，并用与翻题方向一致的横向切换动画保持卷面连续感。
- 每道题直接显示题面、纵向选项、答案与解析。
- 用手指或 Apple Pencil 选中词语后，点击“词典 / 双链”，可查潜在双链、关联已有词条或直接新建收件箱词条。
- 新建词条后不自动展开右侧编辑栏，只建立当前选中原文的双链；整卷/专题补链由标题下方的“查找潜在链接”统一处理。
- 集合级扫描不会直接修改题库；它读取词典已有词条的标题和别名，需要在候选列表中预览、勾选后才写入，并可用命令面板撤销最近一次批量回链。
- 新建收件箱词条后继续保留当前题号、答题状态和滚动位置，不自动占用 iPad 的题面宽度；详细编辑留到 Windows 端处理。
- 快速补充专题、错因、学习状态和 `review_ready`。
- 精读区中的 Obsidian 内部链接可直接点击，并支持 Windows 的 Ctrl+鼠标悬浮预览；点击链接会在新标签页打开，不覆盖当前精读会话。
- “原笔记”和漫游内容里的内部链接打开新笔记后，会按当前模式显示“返回卷子精读 / 返回专题精读 / 返回蒙题 / 返回考试 / 返回考试复盘”；Windows 按钮在顶部，iPad/手机在底部拇指区，页眉按钮与命令面板“返回上次漫游位置”作为备用入口。
- 原笔记的 YAML/笔记属性默认折叠；返回按钮下方提供“展开 YAML / 折叠 YAML”，不修改属性内容。
- 返回时恢复原题号、答题/揭晓状态、卷面方向和滚动位置；即使原漫游标签页被关闭，也会重建视图并恢复会话。
- 每题可标记“精读完成”，写入 `intensive_status`、`intensive_completed_at` 和 `intensive_updated_at`。卷子与专题卡片根据逐题状态实时汇总完成数和百分比，不保存容易失真的集合级缓存。
- Windows 可在题干、选项或解析中选中文字后右键，直接查找相似词条、建立双链或新建词条；iPad 继续使用“词典 / 双链”按钮。

### 蒙题训练

- 进入前可开启“词条双链预览”。默认关闭以防提示泄露；开启后已建双链显示为紫色，可点击或悬浮预览。
- 可设置每题时间，超时自动提交。
- 第一次点击选项只选中；点击其他选项只改选；第二次点击同一个已选选项才提交。
- 提交后在原位置展开解析，不重建整页，不另设干扰操作节奏的“提交答案”按钮。
- 提交后标明正确答案和错选项；再次点击正确答案进入下一题。
- 无法可靠识别答案时保留“下一题”按钮，避免卡住。
- 保存作答、耗时、是否正确和蒙题技巧到题目 YAML。
- 如果原题没有可靠的 A/B/C/D 答案，只显示“无法自动判分”，不会猜答案。

### 设备专注模式

- 手机和 iPad 打开漫游时自动收起 Obsidian 左右侧栏。
- Windows 默认保留侧栏，可在插件设置中开启“打开漫游时收起两侧栏”。
- 插件不会在退出漫游时擅自恢复侧栏，侧栏状态仍可用 Obsidian 自带按钮调整。

### 考试模式

- 进入前可开启“词条双链预览”。默认关闭时所有 Wiki 双链按普通文字显示；开启后用紫色明确标识可预览词条。
- 开始前设置整场时长，开始后倒计时。
- 交卷前隐藏答案、解析、元数据、词典和双链工具。
- iPad 横屏为左侧卷面、右侧窄答题卡；竖屏和手机改为答题卡抽屉。
- 卷面可上下连续或左右分页；选项始终单列，点选后立即涂色。
- 答题卡可跳题，并区分已答、未答、当前题和标记题。
- 交卷后显示已答数、可判分题正确率和总用时。
- 申论等主观题只记录“已作答”，不自动评分。
- Windows / iPad 横屏采用左侧卷面、右侧固定答题卡；答题卡使用本次考试的 1–N 编号，并保留原卷题号说明。
- 右侧答题卡显示作答进度、当前题、已答题和标记题，并提供固定交卷入口。
- 上下连续模式使用鼠标滚轮自然滚动；左右分页模式在题内滚到底或滚到顶后继续滚轮即可切换下一题或上一题。

## 题目格式

插件优先读取以下 YAML：

```yaml
note_type: question
paper_id: 山西-2008-通用卷
paper_title: 2008年山西公务员考试《行测》
region: 山西
year: 2008
subject: 行测
module: 常识判断
question_no: 100
topics: [常识, 常识判断]
mistakes: []
status: new
review_ready: false
```

正文使用独立一行 `?` 分隔题面和答案：

```markdown
题干……
A. 选项
B. 选项
?
答案和解析……

## 来源
……
```

## 安装

将 `main.js`、`manifest.json`、`styles.css` 放入：

```text
.obsidian/plugins/gongkao-note-roamer/
```

然后在 Obsidian 第三方插件中启用“考公笔记漫游”，点击左侧功能区图标或运行命令“打开考公笔记漫游”。

## 已知边界

- 部分旧题答案受 OCR 影响，只剩数字或乱码，这类题无法可靠自动判分，但仍可阅读原解析和手工自评。
- 异常格式题即使没有成功解析成选项，题面行末的答案对勾也会在学习界面隐藏，避免提前泄题。
- 插件的语法、解析和数据逻辑可在构建时自动检查；真实 Obsidian / iPad 的渲染、选区和触控仍应在目标设备上实际验证。


### 0.6.3 Pencil 与局部橡皮
蒙题、考试模式下 Pencil 落笔自动书写；手指继续点选、滚动。鼠标书写仍需手动开启。新增局部橡皮，点击后用 Pencil 擦除，再次点击恢复书写；撤销可恢复上一笔擦除。垃圾桶独立清空整题。临时草稿不写入笔记，不同步，退出即清空。通过指针事件模拟与回归检查，尚未在真实 iPad 上验证。


### 0.6.4 统一解题思路区域
精读、蒙题提交后和交卷复盘解析下，统一显示关联本题的技巧分析（按老师排序展开）和题目原有蒙题总结。可搭配技巧宝典 0.1.1 直接新增本题分析，再点刷新读取；考试作答期间隐藏。支持库内路径和 wiki 链接关联。未关联的讲义/技巧不会自动当成本题分析。
